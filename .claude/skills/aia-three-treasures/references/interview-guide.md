# 友邦三宝访谈问题与信息充足标准

只按当前阶段读取和使用问题。每次选择最有价值的一个问题，**不要一次展示完整题库**。根据用户上一条回答灵活追问，题库是弹药库不是流水线。

## 通用追问方法

优先把抽象回答追问成事实和故事：

- 「大概是什么时候的事？」
- 「当时具体发生了什么？」
- 「那件事之后你做了什么？」
- 「最后的结果或变化是什么？」
- 「中间有没有犹豫、反对或转折？」
- 「你后来怎么想通的？」
- 「这件事你跟别人讲过吗？对方什么反应？」
- 「其中哪些细节你愿意公开讲，哪些只想自己留着？」

### 深层动机追问（挖到用户自己没意识到的东西）

事实层（什么时候 / 发生了什么 / 结果）只是骨架，**真正打动人的是动机和意义**——用户当初怕失去什么、看重什么、那个转折对她意味着什么。这些她自己未必说得清，要靠你追问才浮出来。在问完事实后，挑 1—2 个深问：

- 「那件事最让你害怕 / 舍不得的，到底是什么？」（怕失去什么）
- 「下决心那一刻，真正打动你的不是钱、不是前景，而是什么？」（真正看重什么）
- 「如果不做这个选择，你最遗憾的会是什么？」（没说出口的）
- 「这件事让你对自己、或对家人，有了什么不一样的看法？」（意义、价值观）
- 「你现在回看，那件事教会了你什么？」（提炼，为金句埋种子）

> 这一层最接近参考项目的价值——「引导用户发现自己没意识到的深层东西」。用户答不上来很正常，**用启发式联想帮她**（见下），不要就此跳过。

### 启发式联想：用户回答浅时，主动给方向

当用户的回答停留在表面（只有「就是觉得还不错」「家里人支持」「图个稳定」），**不要干等**，主动给 2—3 个假设方向让她选或补充：

- 「是更像『怕将来后悔』，还是『被某个人的处境触动』？」
- 「你犹豫的那阵子，是在纠结钱、还是面子、还是怕不适合自己？」
- 「如果让你用几个词形容当时的感受，是『焦虑、期待、不舍』里哪几个，还是别的？」

给出方向 ≠ 替她编造：你只是**搭台阶**，最终用哪个意思由她确认。确认后才算「已确认事实」，否则记「待确认」。

把信息标记为四类：

- **已确认事实**：用户明确陈述并确认。
- **用户偏好**：用户希望采用的表述或方向（如「我想突出转型前的专业背景」）。
- **AI 建议**：基于事实给出的写法、措辞或素材框架，不写成用户事实。
- **待确认**：信息不足、存在矛盾或用户不确定。

## 阶段一：讲行业（为什么选择保险行业）

可选问题（按需挑选，不必全问）：

- 你最早是怎么接触到保险的？是某件事、某个人，还是某段经历？
- 在真正考虑做保险之前，你对保险这个行业是什么印象？后来这个印象是怎么变的？
- 是哪一个具体的瞬间或事件，让你认真考虑「我要不要做保险」？
- 身边有没有人支持或反对你做这个决定？他们说了什么？
- 你现在怎么看待保险这个行业的机会？你看到了什么别人可能没看到的东西？
- 为什么觉得现在是一个做保险的好时机？
- 你希望在这个行业里，成为一个什么样的从业者？跟传统的保险销售有什么不一样？
- 如果用一句话跟朋友解释「我为什么做保险」，你现在会怎么说？
- 深层：真正让你下定决心的，是怕失去什么、想抓住什么，还是被谁的处境触动？（先说出事实，再深挖背后的动机——这一层最像真人、最难被复制。）

信息充足标准：能说清**一个真实的契机故事 + 一次认知转变 + 一条自己的行业判断**，而不只是「保险前景好」这种空话。

输出后询问：「以上『讲行业』部分是否准确？有没有哪一点跟你的真实情况不一致，或者想再补充一个细节？」

## 阶段二：讲公司（为什么选择友邦）

可选问题：

- 决定做保险之后，你为什么会选友邦，而不是其他公司？
- 友邦最打动你的，是实力、产品、平台，还是别的什么？具体是哪一点？
- 在你了解友邦的过程中，有没有哪个事实或细节让你觉得「就是它了」？
- 你是怎么加入现在这个团队的？为什么是这个团队、这个引荐人？
- 这个团队什么地方让你觉得待得住、能成长？
- 友邦的经营理念、分红机制、培训体系里，哪一项你最有体感？
- 如果让你跟一个犹豫要不要来友邦的人讲，你会用友邦的哪一点说服他？
- 关于友邦的公司实力、分红、荣誉这些数字，你手头有团队或公司发的准确资料吗？还是需要我们用通用信息、你之后自己核验？

> 涉及友邦公司层面的客观信息时，先读取 [company-profile.md](company-profile.md)：优先用团队已填入的权威资料；未填写的部分用通用素材框架，并明确标注「通用信息，需核验」。

信息充足标准：能说清**一个真实的选友邦理由 + 一个团队/引荐人的链接点 + 至少一项有体感的公司优势**，且公司客观信息的来源状态（团队资料 / 通用素材 / 待核验）标注清楚。

输出后询问：「以上『讲公司』部分是否准确？特别是关于友邦的客观信息，哪些是你能确认的，哪些需要标注为待核验？」

## 阶段三：讲个人（我是谁，凭什么被记住）

可选问题：

- 在做保险之前，你主要做什么工作或事业？那段经历里你最有成就感的是什么？
- 过去的经历里，培养了哪些你现在做保险依然用得上的能力或习惯？
- 朋友一般会用什么词形容你？你觉得准吗？
- 你有没有一段经历，是你跟别人聊天时特别愿意讲、对方也特别爱听的？
- 你服务或最想服务的是什么样的人？为什么是你能服务好他们？
- 你希望别人提起你的时候，第一个想到的是什么？
- 你身上有没有一个有点特别、甚至有点反差的小特点，是别人容易记住的？
- 有没有什么爱好、习惯或身份，能让你跟某类客户一聊就觉得亲近？
- 深层：你身上有没有一个连你自己都说不清、但别人总被吸引的点？（联想方向：是反差、是较真、还是某种温柔？）

信息充足标准：能说清**过往经历带来的能力 + 至少一个能产生共鸣的真实链接点 + 想被记住的样子**，并且这些都有事实支撑，不是自我标榜。

输出后询问：「以上『讲个人』部分是否准确？尤其那个『能让人记住的点』，你觉得真的代表你吗？」

## 阶段四：成稿前的必要信息

在生成多场景版本前，确认以下几点（大多可从前三部分继承，缺失才追问）：

- 完整版主要用于什么场合（面谈、社群分享、正式介绍）？这决定详略和语气。
- 是否愿意在朋友圈/社群版本里露出真实姓名、过往职业、所在城市等个人信息？
- 有没有明确不想出现的词、表达或人设（例如不想被叫「销售」、不想强调收入）？
- 是否需要包含联系方式、团队信息或一句行动号召（如「欢迎找我聊聊家庭保障」）？
- 多场景版本里，哪个版本你会最先实际用出去？（优先把它打磨到位。）
- 是否需要小红书版（钩子 + 口语）和公众号版（稍长、小标题）？如果常发这两个平台，优先准备好；不同平台的语气和长短差异很大。

信息充足标准：知道完整版的用途、个人信息公开边界、禁忌表达，以及用户最在意先打磨哪个版本。

最终询问：「这是将写入文件的最终友邦三宝。是否确认采用？如果要改，请直接指出具体位置。」
