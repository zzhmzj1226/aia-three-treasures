# 友邦三宝助手（AIA Three Treasures）

一个 [Claude Code](https://docs.claude.com/en/docs/claude-code) Skill，帮助友邦（AIA）保险代理人通过**一对一渐进式问答**，梳理并写出一版真实、可用、可持续迭代的「友邦三宝」自我介绍。

> **友邦三宝** = 讲行业（为什么做保险）+ 讲公司（为什么选友邦）+ 讲个人（我是谁、凭什么被记住）。

助手会主动推进整个流程，你只需回答问题、逐段确认，无需记忆任何指令。最终文稿会**写入你的 Obsidian 个人知识库**，成为可长期复用、链接、迭代的活文档。

---

## 🚀 快速开始（一句话安装）

在你的 **Obsidian Vault 根目录**里（需含 `00_个人背景/` 文件夹），把下面这句丢给你的 Claude Code：

```
从 github.com/zzhmzj1226/aia-three-treasures 把 skill 装进当前 Vault 的 .claude/skills/，然后带我走一遍「友邦三宝」，结果写入 00_个人背景/友邦三宝_v1.md。
```

或用一行命令安装：

```bash
git clone https://github.com/zzhmzj1226/aia-three-treasures.git /tmp/aia-3b && mkdir -p .claude/skills && cp -R /tmp/aia-3b/.claude/skills/aia-three-treasures .claude/skills/ && rm -rf /tmp/aia-3b && echo "✓ 装好了，对 Claude 说『帮我设计友邦三宝』"
```

> 没装过 Obsidian / 没有 `00_个人背景/`？先看下方「⭐ 使用前准备」。

## 它解决什么问题

很多代理人写三宝时容易陷入三个坑：

1. **像填表** —— 堆砌公司宣传话术，不像一个真实的人在介绍自己；
2. **写空话** —— 「行业前景广阔」「公司实力雄厚」，没有自己的真实故事；
3. **编造信息** —— 拍脑袋补业绩、排名、分红数字，埋下合规风险。

本助手通过**渐进式访谈**收集你的真实素材，严格区分「已确认事实 / 用户偏好 / AI 建议 / 待确认」四类信息，**绝不替你编造**任何头衔、业绩或数字，最终生成可直接对外使用的文稿。

## ⭐ 使用前准备：个人知识库（Obsidian）

本 Skill 采用**强 Vault 模式**：必须在 Obsidian Vault 里运行，最终文稿写入你的个人知识库，而不是散落在某个项目文件夹。

使用前请完成：

1. 在 Obsidian 中创建或打开一个 Vault（例如「我的第二大脑」）。
2. 在 Vault 根目录下确保存在 `00_个人背景/` 目录（与生财「第二大脑」内容创作系统结构一致；若你已用那套结构则无需改动）。

   推荐最小结构：
   ```
   <你的 Vault>/
   └── 00_个人背景/        ← 三宝文件写到这里
   ```
3. 用 Claude Code 打开**这个 Vault 目录**。

如果检测不到 Vault 或 `00_个人背景/`，Skill 会暂停并提示你缺什么，不会继续访谈、也不会乱建目录。

## 安装：把 Skill 装进你的 Vault

clone 本仓库后，把 Skill 目录放进你的 Obsidian Vault 的 `.claude/skills/` 下：

```bash
git clone https://github.com/zzhmzj1226/aia-three-treasures.git
cp -r aia-three-treasures/.claude/skills/aia-three-treasures "<你的Vault路径>/.claude/skills/"
```

然后用 Claude Code 打开你的 Vault 目录，对它说「帮我设计我的友邦三宝」即可触发。

> 为什么不能在仓库目录里直接用？因为本 Skill 启动时会检测 Obsidian Vault（`.obsidian/` 目录），仓库本身不是 Vault，直接用会触发暂停。Vault 是你的个人知识库，Skill 要在里面读写你的笔记。

## 使用

在你的 Vault 目录下（用 Claude Code 打开），说任意一句即可自动触发：

- 「帮我设计我的友邦三宝」
- 「我想梳理一下三宝自我介绍」
- 「我已经有一版三宝，想优化一下」
- 「帮我准备友邦三宝」

助手会依次带你走完四个阶段，每段生成初稿、请你确认后自动进入下一段：

1. **讲行业** —— 进入保险行业的契机、认知转变、行业判断
2. **讲公司** —— 为什么是友邦、认同的特质、团队支撑
3. **讲个人** —— 过往经历、个人特质、可被记住的链接点
4. **成稿** —— 完整版 + 面谈/朋友圈/社群/一句话电梯版 + 个人标签卡

全部确认后，助手会自动写入 `<你的 Vault>/00_个人背景/友邦三宝_v1.md`。后续迭代只需说「帮我优化三宝的讲个人部分」，会按 v1.1 / v1.2 递增更新、保留历史。

## 三条回答原则（助手启动时会提醒）

1. 讲真实经历、具体时间、实际动作和真实结果；
2. 想不起来就直说「暂时想不起来」，助手会提供回忆方向，绝不替你编造；
3. 每段初稿认真核对，发现不准的地方直接指出。

## 重要边界

- 三宝的主角是「这个人」，公司素材只是认同点的支撑，不是公司广告。
- 分红实现率、市场排名等数字会变，助手会提示以最新官方披露为准，绝不写成确定承诺。
- 业绩、收入、职级等敏感信息，只在代理人主动明确提供时才使用，不诱导、不推测、不美化。
