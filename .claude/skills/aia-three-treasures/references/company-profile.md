# 友邦公司素材库（含团队资料预留区）

本文件是「讲公司」部分的素材来源。**助手使用规则：**

1. **最高优先级**：先看下方「一、团队与个人权威资料」是否已填写。已填入的内容视为可信赖事实，优先采用。
2. **兜底素材**：团队资料未覆盖的部分，使用「二、友邦通用素材框架」。但其中所有内容都是**通用方向，不是经过核验的事实**，写入文稿时必须标注「通用信息，需结合本地实际情况和最新官方数据核验」。
3. **绝不编造数字**：分红实现率、市场排名、MDRT 人数、资产规模等会随时间变化的具体数字，本文件一律不填具体值。若用户无法提供准确数字，就写「待核验」，**绝不凭印象补一个数字**。
4. **敏感信息**：业绩、收入、职级、客户数等，只在用户主动且明确提供时使用。

## 二、友邦通用素材框架（兜底，均需核验）

> 以下每个维度只提供「常被采用的讲述方向」，**不含具体数字**。使用时必须结合用户的真实认同点，并标注为「通用信息，需核验」。不要把这些当成已确认事实写进文稿。

### 1. 品牌与历史维度

常被采用的讲述方向：

- 友邦是具有百年历史的保险品牌（具体成立年份、在华历史节点**需核验**）；
- 在中国内地保险市场的发展历程中占据特殊位置（如改革开放后回归内地市场的故事，**细节需核验**）；
- 「百年老店」带来的长期稳健印象。

**写作提醒**：历史是用来支撑「稳健、可信」的感受，不是炫耀资历。要落到用户为什么在意这种稳健。

### 2. 市场地位维度

常被采用的讲述方向：

- 在外资/合资保险品牌中的市场形象；
- 品牌在高端客户、专业代理人群体中的认知度；
- 上市保险公司（母公司 AIA Group 上市背景，**具体信息需核验**）。

**写作提醒**：避免堆砌「第一」「最大」等未经核验的排名。市场地位要服务于「我为什么相信这家公司能长期陪客户」。

### 3. 经营与分红维度

常被采用的讲述方向：

- 友邦的经营稳健性、长期盈利能力（**具体财务数据需以最新官方披露为准**）；
- 分红型产品、长期储蓄类产品的理念；
- 「做保险、买保险最终可能都会考虑友邦」背后的经营逻辑。

**写作提醒**：分红实现率、收益率是**最敏感的数字**，必须使用最新官方披露，且不得承诺未来收益。写「待核验」比写一个可能过时的数字更负责。

### 4. 产品与平台维度

常被采用的讲述方向：

- 产品体系覆盖保障、储蓄、健康等多条线；
- 「以客户为中心」的需求导向销售理念；
- 跨地域服务能力（如大湾区相关布局，**具体政策需核验**）。

**写作提醒**：产品是讲给客户的，三宝里只需点到「平台足够支撑我把专业做深」即可，不必展开产品细节。

### 5. 培训与个人发展维度

常被采用的讲述方向：

- 完善的培训体系和专业成长路径；
- MDRT（百万圆桌）文化与绩优代理人氛围（**团队 MDRT 数据需核验**）；
- 把普通人培养成专业财富规划/保障顾问的机制。

**写作提醒**：这一维度最贴近「为什么能在这里成长」，是新人讲公司的常用抓手，但要落到用户自己的体感（如「我参加的某次培训让我……」）。

### 6. 价值观维度

常被采用的讲述方向：

- 「健康、长久、好生活」类的品牌主张（**具体表述以官方为准**）；
- 长期主义、专业主义的服务文化；
- 对代理人的尊重与职业化定位。

**写作提醒**：价值观是最容易写空的部分。只有当用户能讲出自己「感受到」的一个具体瞬间时才用，否则宁可不写。

## 三、核验原则

- 任何具体数字（成立年份、分红实现率、市场排名、MDRT 人数、资产规模、客户数）出现时，必须在文稿中标注来源状态：`【团队资料】` / `【通用信息·需核验】` / `【待核验】`。
- 分红、收益类内容**严禁**写成确定承诺，必须保留「以最新官方披露为准」的提示。
- 团队/引荐人信息只在「一、团队与个人权威资料」已填写、且用户确认可对外提及时，才写入文稿。
- 用户的个人业绩、收入、职级，只在用户主动明确提供时使用，写入时标注为用户提供。
