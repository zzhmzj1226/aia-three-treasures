# 友邦三宝助手

引导友邦代理人设计或迭代自己的「友邦三宝」自我介绍——**讲行业、讲公司、讲个人**三段式。通过一对一渐进问答收集真实素材，逐段确认后生成可用的完整文稿与多场景版本。

设计蓝本参照了 `shengcai-positioning-interview`（航海定位官）的渐进式访谈模式。

---

## 怎么触发

在本项目目录下，对 Claude 说类似的话即可自动触发：

- 「帮我设计我的友邦三宝」
- 「我想梳理一下三宝自我介绍」
- 「我已经有一版三宝，想优化一下」
- 「帮我准备友邦三宝」

助手会主动推进流程，你只需回答问题、逐段确认，无需记忆任何指令。

---

## 文件结构

| 文件 | 作用 |
|------|------|
| `SKILL.md` | 主流程：启动、对话规则、四阶段（讲行业→讲公司→讲个人→成稿）、自动写入、完成标准 |
| `references/interview-guide.md` | 三阶段可选问题、追问方法、四类信息分级、信息充足标准 |
| `references/company-profile.md` | **友邦公司素材库（含团队资料预留区）**——见下方说明 |
| `references/storytelling-guide.md` | 三宝写作指南：叙事逻辑、每段锚点、链接点挖掘、禁忌、验收标准 |
| `references/output-templates.md` | `友邦三宝_v1.md` 的固定结构与更新规则 |

## ⭐ 重要：填充公司资料（company-profile.md）

「讲公司」部分需要友邦的事实素材。目前 `references/company-profile.md` 只内置了**通用素材框架**（百年历史、市场地位、经营分红、产品平台、培训发展、价值观等维度），**不含任何具体数字**——所有数据维度都标注了「需核验」。

要让三宝里的公司信息更准确、更有团队特色，请把团队 / 分公司的权威资料填进该文件的 **「一、团队与个人权威资料」** 区：

- 团队名称、所在营业部、规模
- 团队核心荣誉与数据（MDRT 人数、奖项——填准确数字与年份）
- 团队文化 / 特色 / 提供的支持
- 引荐人称呼与亮点（确认是否愿意对外署名）
- 分公司可公开的成绩、分红 / 经营数据（注明来源和日期）

**填了之后，助手会优先使用这些资料，并标注为 `【团队资料】`；未填的部分继续用通用框架，并标注 `【通用信息·需核验】`。** 这样既保证灵活性，又不会传播未经核验的数字。

---

## 使用流程

1. **（可选但推荐）** 先把团队权威资料填进 `references/company-profile.md`。
2. 触发 Skill，按四阶段回答问题：
   - 讲行业 → 讲公司 → 讲个人 → 成稿
3. 每个阶段生成初稿后认真核对，指出不准的地方，确认后自动进入下一阶段。
4. 全部确认后，助手自动在项目目录生成 `友邦三宝_v1.md`（含完整文稿、面谈/朋友圈/社群/一句话电梯版、个人标签卡、素材库）。
5. 后续迭代只需再说「帮我优化三宝的讲个人部分」，助手会读取已有文件、保留历史、按 v1.1 / v1.2 递增更新。

---

## 三条回答原则（助手启动时会提醒）

1. 讲真实经历、具体时间、实际动作和真实结果；
2. 想不起来就直说「暂时想不起来」，助手会提供回忆方向，绝不替你编造；
3. 每段初稿认真核对，发现不准的地方直接指出。

## 重要边界

- 三宝的主角是「这个人」，公司素材只是认同点的支撑，不是公司广告。
- 分红实现率、市场排名等数字会变，助手会提示以最新官方披露为准，不写成确定承诺。
- 业绩、收入、职级等敏感信息，只在代理人主动明确提供时才使用，不诱导、不推测、不美化。
