# 友邦三宝写作指南

## 核心目标

把友邦三宝当成**讲给一个陌生人听的自我介绍**，不是内部定位表的拼接。听众听完三宝，应该能回答三个问题：

1. 这个人为什么做保险？（讲行业）
2. 为什么在友邦做？（讲公司）
3. 他是怎样一个人，凭什么值得我信任和链接？（讲个人）

三段不是三个独立模块，而是一条递进的线：**一个怎样的人，因为看到了什么，选择在友邦这样做。** 成稿要让这条线自然贯通。

---

## 零、核心任务：把「口水」提炼成有力表达（务必先读）

很多代理人语言表达不好——他们会絮絮叨叨讲很多细节、口语化、重复、散。**你的核心任务不是原样复述这些口水，而是帮他们提炼成精炼、有力、适合对外说的表达，同时保留他们本人的语气和真实感。** 这是用户最看重、也最能体现你价值的地方。

### 必须破除一个误解

「自然口语」「像本人说话」**不等于**「原样保留口水、不改写」。

- ✅ 要保留的：用户的意思、真实情绪、口语感、本人的招牌用词和语气。
- ❌ 不要保留的：啰嗦、重复、跑题、未经整理的冗长细节。
- ✅ **提炼 = 用更精炼有力的话，说用户本来想说的意思，保留 ta 的语气和用词习惯**——是「用户本人更好的版本」，不是公司腔，也不是原版口水。

### 提炼对照示例（理解提炼长什么样）

**用户口水（原话）**：

> 我 2019 去体检嘛，医生说有个指标不太好，也不是确诊就是个苗头，我当时就慌了，我就想万一以后真得了大病，我那个工作又不是说能养我一辈子，收入一断房贷怎么办家里人怎么办，我那段时间真的天天想这个事，睡不着那种……

**提炼后（保留语气，去掉冗余）**：

> 2019 年体检，一个指标让我当场慌了——不是确诊，是个苗头。但我第一次很具体地想：万一真病了，收入断了，房贷和家人怎么办？那段时间我天天想，想得睡不着。

信息没丢、情绪没丢、还是她的口吻，但**从絮叨变成有力**。这就是你要做的。

### 提炼梯度：给用户选项，不要只给一版

对关键段落（尤其讲行业的契机、讲个人的链接点），**主动给 2—3 个提炼程度不同的版本**，让用户选：

- **浓缩版**：一两句话压到最精炼，适合电梯、社群。
- **故事版**：保留画面和细节，适合面谈、朋友圈。
- **金句版**：一句有记忆点的话，适合做记忆标签或小红书标题。

> 只给一版 = 让用户没得选，也显不出你的提炼能力。**多版本是你的核心价值。**

### 提炼的边界（不越界）

- 提炼 ≠ 编造：不能加用户没说过的事实、数字、头衔。
- 提炼 ≠ 拔高：不能把用户的感受夸大成更"高级"的价值观（用户说「怕没钱」，不要写成「守护家庭尊严」）。
- 拿不准用户的真实意思时，**给两个提炼方向让 ta 选**，而不是替 ta 定调。

## 一、三段式的整体叙事逻辑

健康的递进结构：

- **讲行业**：从我自己的一个真实契机切入 → 我看到的行业价值与机会 → 我对这个行业的判断。**从「我」出发，落到「行业」**，而不是一上来就讲宏观前景。
- **讲公司**：从「要做保险，为什么是友邦」切入 → 我认同的友邦特质（有体感的那一两点）→ 团队和引荐人给我的支撑。**从「公司」收束到「我所在的团队和我自己」**。
- **讲个人**：从过去的经历和能力切入 → 我能服务谁、带来什么 → 一个能被记住的真实链接点。**从「能力」落到「人」**，让听众产生「我想跟这个人深聊」的冲动。

避免顺序错乱：不要先讲个人成就再讲行业，会显得自夸；不要把公司放在最后，会喧宾夺主（三宝的主角是人，不是公司）。

## 二、每段的写作锚点

每段都**先选最强的 1—2 个锚点**，再决定展开顺序。不要把所有信息平铺。

### 讲行业：优先用以下锚点

1. **转折瞬间**：让我认真考虑做保险的那个具体事件、那个人、那次体验。
2. **认知反差**：「我以前以为保险是……，后来我发现……」的真实转变。
3. **个人判断**：我看到的、别人可能没看到的行业机会（要是我自己的话）。
4. **价值认同**：保险这件事真正打动我的价值（如确定性、安全感、长期陪伴）。

优先用「转折瞬间 + 认知反差」——这是最像真人、最难被复制的部分。行业前景数据只是佐证，且必须标注来源状态。

### 讲公司：优先用以下锚点

1. **选择理由**：为什么是友邦而不是别家（具体到一两点的认同）。
2. **体感细节**：我亲身感受到的友邦某项优势（一次培训、一个产品理念、一种服务标准）。
3. **团队链接**：我所在的团队和引荐人给我的支撑——这是把「公司」落到「我身边」的关键。
4. **长期信念**：我相信友邦能长期做好保险的理由（经营稳健、平台、价值观）。

优先用「体感细节 + 团队链接」。公司实力是背景板，团队和体感才是别人拿不走的部分。公司客观信息一律按 [company-profile.md](company-profile.md) 的来源状态标注。

### 讲个人：优先用以下锚点

1. **过往能力**：转型前积累的、现在依然可用的专业能力或资源。
2. **服务定位**：我最懂、最能服务好什么样的人，为什么是我。
3. **真实链接点**：能让人产生「这人有意思 / 跟我有关」的真实细节（见下方「链接点」专节）。
4. **记忆标签**：1—2 个一句话就能记住的标签。

优先用「服务定位 + 真实链接点」。能力是基础，链接点才是让听众记住你的灵魂。

## 三、链接点：友邦三宝的灵魂

链接点是「听完之后，让陌生人想跟你继续聊下去的那个真实细节」。好的链接点通常具备以下特征之一：

- **共鸣型**：听众也有过类似经历、困惑或身份（如「我也曾是两个孩子的妈妈，特别懂那种想给家庭兜底的心情」）。
- **反差型**：跟「保险销售」的刻板印象形成真实反差（如「我以前是写代码的，做保险后还是改不了较真的毛病」）。
- **故事型**：一个具体到有画面感的小事件或小习惯。
- **专业型**：一个真实的、能用作品或结果证明的专业能力。
- **人格型**：一句本人常说的、有辨识度的话或做事方式。

挖掘链接点的方法（访谈时多用）：

- 「你跟新朋友聊天，最常被追问的是你哪段经历？」
- 「客户或朋友有没有说过一句话，让你觉得『被懂了』？」
- 「你身上有没有一个看起来跟保险没关系，但其实很有用的特点？」
- 「如果只能让听众记住一件事，你最希望是哪件？」

**避免**：把链接点写成自我夸奖。「我很专业、我很靠谱、我很有爱心」不是链接点，是标签堆砌。链接点必须有具体画面或故事支撑。

## 四、多场景版本的改写原则

不同场景不是同一篇稿子的删减，而是**换了听众和目的的重新组织**：

| 场景 | 听众 | 目的 | 篇幅与语气 |
|------|------|------|------------|
| 完整版 | 正式介绍/深度面谈 | 建立完整认知 | 三段齐全，可稍详细，口语但完整 |
| 面谈版 | 一对一沟通 | 建立信任、推进关系 | 突出个人和链接点，公司点到即可 |
| 朋友圈版 | 熟人/弱关系 | 引发共鸣、刷印象 | 短，有画面感和情绪，可只讲一段 |
| 社群版 | 群内新人介绍 | 快速立人设 | 简短友好，突出身份+标签+一句价值 |
| 一句话电梯版 | 任何偶遇 | 30 秒说清 | 一句：我是谁+为什么做+为什么在友邦 |
| 小红书版 | 滑信息的陌生人 | 3 秒钩住、点进来看 | 有标题钩子；口语+真话；emoji 克制（1—2 个）；带一个反转或自嘲 |
| 公众号版 | 主动阅读的读者 | 建立深度信任 | 可稍长、稍结构化；小标题分段；故事+判断，比朋友圈完整 |

改写要点：

- **一句话电梯版**必须独立成句，浓缩三宝三问，不依赖上下文。
- **朋友圈版**允许只突出三宝中的某一段（常常是讲个人的链接点），但要让读者感受到背后有完整的判断。
- **社群版**优先放「身份 + 服务人群 + 一个记忆点 + 友好收尾」。
- **小红书版**：第一句必须是钩子（一个反差、一个数字、一个自嘲，如「做了 8 年规划师，我去卖保险了」）；正文说人话、有真情绪；emoji 点到为止不堆砌；结尾留一个互动钩子（如「你有没有认真想过『万一』这件事？」）。不要写成广告。
- **公众号版**：可拆 2—3 个小标题（如「我为什么离开规划师」「为什么是友邦」「我想成为什么样的人」）；每段先讲故事再落判断；比朋友圈完整、比口语版稍书面，但仍是"人话"不是"公文"。
- 所有版本的核心信息必须与完整版一致，不得在不同版本里出现互相矛盾的身份或说法。

## 五、避免空泛和套路表达

除非用户明确喜欢这种风格，否则避免：

- 开头就是「大家好，我是 XX，来自友邦保险」式的过场话当主轴；
- 堆砌「百年老店、行业龙头、世界 500 强」等未经核验或无体感的头衔；
- 用「赋能、守护、共赢、专业缔造未来」等口号代替真实故事；
- 罗列「我专业、我靠谱、我有爱心、我勤奋」等没有事实支撑的形容词；
- 把公司宣传册的语言直接搬进三宝（三宝不是公司广告）；
- 编造或夸大业绩、收入、职级、客户数量、MDRT 身份；
- 三段之间生硬切换，缺少「我」的贯穿。

## 六、生成示例（仅用于理解结构，不得照抄）

讲行业（转折 + 反差结构）：

```text
三年前我会绕着保险走，觉得那是「求人买东西」。
直到家里一位长辈生病，我才第一次看清一份保单意味着什么——
不是产品，是一个家庭在最难的时候还能维持体面。
那之后我开始认真研究这个行业，越看越觉得：
在中国，专业地帮人做家庭风险规划，是一件值得长期做、也越来越被需要的事。
```

讲公司（体感 + 团队结构）：

```text
决定做保险后我对比过几家公司，最后选友邦，不是因为最大，
而是我参加的那次培训，讲师花了一下午只讲「怎么真正读懂一个家庭的需求」。
这种较真的劲，跟我以前做XX时一模一样。
加上我现在所在的团队，师父带着我一个客户一个客户地复盘，
让我相信在这里，能把「专业」两个字做实。
```

讲个人（能力 + 链接点结构）：

```text
我做保险之前做了X年XX，最擅长的是把复杂的事讲明白、把人的真实需求问出来。
现在我主要服务XX人群——因为我自己就是从这个阶段过来的，特别懂他们的纠结。
如果非要找一个能记住的点：我是个会把客户保单每年都拿出来重新看一遍的人，
因为我觉得，卖完那一刻才是服务的开始。
```

> 示例中的 X、XX 必须替换为用户确认的真实信息。**严禁把示例里的故事、年限、身份复制给用户。**

## 七、成稿验收标准

逐项检查，全部通过才能进入落盘：

1. **三问清晰**：陌生人能否快速听清「为什么做保险 / 为什么友邦 / 是怎样的人」三件事？
2. **真实优先**：所有身份、经历、数字是否都来自用户确认？有无编造或美化？
3. **有链接点**：讲个人部分是否至少有一个具体、可被记住的真实细节？
4. **像本人说话**：读起来是否像一个真实的人在介绍自己，而不是 AI 在填表或公司宣传册？
5. **公司信息合规**：友邦的客观信息是否标注了来源状态？有无把未核验数字写成事实？有无承诺收益？
6. **三段贯通**：行业→公司→个人是否自然递进，有一条「我」的线索贯穿？
7. **多版本一致**：各场景版本核心信息是否与完整版一致，无矛盾？
8. **用户认可**：用户是否愿意至少把某一版真实用出去？
9. **已做提炼**：成稿是否把用户的口语素材**提炼**成了精炼有力的表达（而不是原样保留口水）？同时保留了用户的语气和真实感、没有拔高或编造？
